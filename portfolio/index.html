Rotin-IA

O Rotin-IA é um projeto de API, com o objetivo de facilitar os estudos de varios estudantes, O projeto conta com funções de gerar rotina de estudo personalizada de acordo com cada usuario, gerar questões e respostas de materias, conteudos e dificuldade variavel de acordo com a preferencia do usuario, possui tambem uma parte que o estudante é avisado sobre olimpiadas de conhecimento e vestibulares, o projeto atualmente esta inacabado sem expectativa de termino

Coin-Run

O Coin Run é um projeto de jogo desenvolvido em Python com a biblioteca Pygame, com o objetivo de colocar em prática conceitos de lógica de programação e desenvolvimento de jogos, O projeto conta com um personagem controlado pelo jogador em um mapa, onde é possível se movimentar utilizando as teclas SPACE, A, D ou as setas esquerda e direita, coletar as moedas disponíveis pelo cenário e acompanhar a pontuação que é atualizada a cada coleta, durante o desenvolvimento foram trabalhados temas como movimentação de objetos, detecção de colisões, estruturas condicionais, funções, variáveis e organização de um projeto de software, o jogo inicia normalmente , o personagem aparece no mapa e as mecânicas de coleta e pontuação funcionam conforme o esperado, porem não há animações
