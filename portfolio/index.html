Personal Projects

Rotin-IA

Rotin-IA is an API project that aims to make studying easier for students. It can generate a personalized study routine for each user, create questions and answers on subjects, topics and difficulty levels chosen by the user, and notify students about knowledge olympiads and university entrance exams. The project is currently unfinished, with no expected completion date.

- It has a working backend that generates study routines organized by days and hours, but I did not work on the frontend, so the generated routines appear unformatted there.

Coin-Run

Coin Run is a game developed in Python with the Pygame library, created to practice programming logic and game development concepts. The player controls a character on a map, moving with the SPACE, A and D keys or the left and right arrows, collecting the coins around the scene while a score updates with each coin. During development I worked on object movement, collision detection, conditional structures, functions, variables and software project organization. The game starts normally, the character appears on the map and the collection and scoring mechanics work as expected, but there are no animations.
