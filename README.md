🚀 Portfólio Pessoal

Este projeto é o meu site de portfólio pessoal, desenvolvido para apresentar meus projetos, conhecimentos, experiências e interesses na área de tecnologia.

O site foi criado com foco em uma interface moderna, simples e responsiva, reunindo em um único lugar informações sobre minha trajetória e os projetos que venho desenvolvendo.

🌐 Sobre o projeto

O portfólio funciona como uma página pessoal para apresentar meu trabalho e acompanhar minha evolução na área de programação.

🛠️ Tecnologias

O site foi desenvolvido utilizando tecnologias web:

HTML5 para estrutura
CSS3 para estilização e responsividade
JavaScript para interações e funcionalidades
🎨 Design

O projeto utiliza uma identidade visual baseada em uma estética tecnológica e minimalista.

A interface foi pensada para destacar os projetos e informações importantes sem deixar a navegação visualmente carregada.

Também foram utilizadas animações e elementos gráficos para deixar a experiência mais dinâmica.

📱 Responsividade

O site foi desenvolvido para funcionar em diferentes dispositivos, incluindo:

💻 Computadores
💻 Notebooks
📱 Smartphones
📱 Tablets

O layout se adapta ao tamanho da tela para manter a navegação e o conteúdo acessíveis.

🚀 Executando o projeto

Para visualizar o site localmente, basta clonar o repositório:

git clone https://github.com/israelvaz121/portfolio.git

Depois, entre na pasta do projeto:

cd portfolio

E abra o arquivo:

index.html

O projeto também pode ser executado utilizando uma extensão como Live Server no VS Code.
